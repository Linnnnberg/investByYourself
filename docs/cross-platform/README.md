## 🎯 **Usage Guidelines**

### **When to Use Cross-Platform Docs**
- Documentation that affects multiple modules
- System-wide architecture decisions
- Development environment setup
- CI/CD and deployment processes
- Troubleshooting that spans modules

### **When to Use Module-Specific Docs**
- Feature-specific documentation
- Module-specific architecture
- Module-specific user guides
- Module-specific troubleshooting

## 🔄 **Maintenance**

Cross-platform documentation should be:
- Updated when system-wide changes occur
- Reviewed quarterly for relevance
- Moved to module-specific docs when appropriate
- Kept minimal and focused on cross-cutting concerns
